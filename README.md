# Real-Time Stress Detection System for Gamers

## Overview
This project predicts stress levels using physiological signals such as Heart Rate (HR), Heart Rate Variability (HRV), and gameplay intensity.

## Features
- Data preprocessing
- Feature engineering (HR, HRV)
- Machine learning model (Random Forest)
- Real-time stress prediction simulation
- Streamlit dashboard

## Tech Stack
- Python
- scikit-learn
- pandas
- Streamlit

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
